# Project Overview
This project analyzes Hospital Consumer Assessment of Healthcare Providers and Systems (HCAHPS) patient surveys data provided by Maven Analytics. The data was analyzed and visualized with Google Sheets.
# Project Objective
The objective of this project is to determine whether hospitals have improved their quality of care over the period analyzed, what areas that hospitals have made more progress in, and whether there are any major areas of opportunity.
# Key Findings
  - 7 of the 10 patient experience measures decreased and 3 remained the same between 2015 and 2023 survey reports
  - No measures increased in top-box (most positive) responses
  - Communication about Medicines had the largest decline in top-box responses
  - Communication about Medicines has the highest bottom-box (least positive) responses
# Recommendations
  - Improve communication about medications to patients
  - Focus on improving areas with higher bottom-box responses
